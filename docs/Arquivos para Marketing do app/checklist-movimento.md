# Checklist — Montando o "movimento" antes de lançar

> Organização da base antes de criar conteúdo. Marque conforme for avançando.

---

## 1. Fundação do perfil

- [x] **Bio reescrita** — versão final (111 caracteres):
  ```
  Perdi tudo que achava certo — e estou aprendendo a reconstruir do zero 🧩
  👀 o que nasceu disso, quero te mostrar
  [link na bio]
  ```
- [ ] **Link na bio** — precisa de um destino (linktree, landing page simples, ou formulário direto de lista de espera). *Isso conecta com o ponto 3 que você já tinha levantado antes (página da lista de espera) — vamos deixar pra depois, mas já fica marcado aqui como dependência.*
- [ ] **Nome de usuário / nome de exibição** — revisar se ainda faz sentido pro que você vai comunicar agora, ou se precisa de ajuste
- [ ] **Foto de perfil** — revisar se ainda representa como você quer aparecer nessa nova fase

## 1.5 Estratégia de idioma (PT/ES)

- [x] **Decisão tomada:** cada peça de conteúdo é monolíngue (sem fala num idioma + legenda traduzida noutro) — a mistura acontece no perfil como um todo, não dentro de cada vídeo
- [x] **História pessoal (arco de origem):** começa em **português** — é onde há engajamento real hoje (mesmo pequeno), apesar da base de seguidores ser majoritariamente hispanofalante
- [ ] **Reativação do público hispanofalante:** planejar, depois que o arco em português rodar, um "recap" em espanhol reapresentando a jornada pra essa base adormecida
- [x] **Conteúdo educacional:** pode alternar entre português e espanhol por peça, sem depender da sequência da história

## 2. Destaques (Stories Highlights)

- [ ] Definir estrutura de destaques. Sugestão inicial de categorias (validar com você):
  - **Minha história** (a origem, o divórcio como evento, a reconstrução)
  - **Bastidores** (construção do app, decisões, processo)
  - **O app / Maya** (o que é, quando chega, funcionalidades traduzidas emocionalmente)
  - **Lista de espera** (como entrar, o que ganha por entrar cedo)
- [ ] Criar capas visuais consistentes pros destaques (mesma paleta do app? Isso ajuda a criar reconhecimento visual desde já)
- [ ] Gravar/reunir o conteúdo de stories que vai virar cada destaque

## 3. Framework de mensagem (feature → emoção)

- [x] Lista de features recebida
- [x] Tradução emocional de cada módulo feita (ver documento `traducao-emocional-features.md`)
- [x] Roda da Vida definida como módulo-âncora pra conectar com a história pessoal
- [ ] Validar com você quais dessas traduções realmente "soam como você" antes de virar conteúdo (isso fica pra quando chegarmos na etapa de conteúdo)

## 4. Arco de conteúdo (sequência ao longo das semanas)

- [ ] Mapear os "capítulos" da história que serão contados aos poucos (não tudo de uma vez)
- [ ] Intercalar com conteúdo educacional (temas que conectam com o mecanismo do app: sono, padrões, decisões no automático, etc.)
- [ ] Definir cadência realista (quantos Reels/posts por semana você consegue sustentar sem queimar o processo)
- [ ] Marcar em que ponto do arco a lista de espera é aberta/anunciada oficialmente

| Dia | Conteúdo |
|---|---|
| Segunda | **Dia 1 — O gancho:** história pessoal (evento + erro assumido), sem mencionar o app. Termina em loop aberto. |
| Terça | **Dia 2 — A virada:** o aprendizado, ponte pro mecanismo (Roda da Vida como conceito), ainda em tom pessoal. Novo loop aberto. |
| Quarta | Dia de respiro — stories de bastidores (sem post principal), mantém expectativa. |
| Quinta/Sexta | **Lançamento:** anúncio formal da Maya + CTA "teste grátis 7 dias, sem cartão" + link na bio. Reforçar via Stories o dia todo. |
